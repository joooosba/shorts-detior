# 🎬 쇼츠 스튜디오 (shorts-editor)

유튜브 쇼츠 · 인스타 릴스 · 네이버 클립용 **9:16 세로(1080×1920)** 영상을 브라우저에서 바로 편집하고 저장하는 웹 편집기입니다.
서버·계정·설치가 필요 없고, 올린 파일은 어디로도 전송되지 않습니다(모든 처리는 브라우저 안에서).

- 주소(배포 후): https://joooosba.github.io/shorts-editor/

## 기능

| 구분 | 내용 |
| --- | --- |
| 캔버스 | 1080×1920 세로 출력, 다크 테마 반응형 UI |
| 안전 영역 | 상단 10%(채널명·검색) / 하단 22%(캡션) / 우측 22%(좋아요·댓글) 점선 가이드 토글 — 미리보기 전용, 저장 영상에는 안 그려짐 |
| 미디어 | JPG·PNG·WebP 이미지, MP4·MOV·WebM 짧은 클립 다중 업로드(드래그 앤 드롭) |
| 타임라인 | 위/아래 순서 이동, 복제, 삭제, 전체 길이 · 60초 권장 안내 |
| 컷 편집 | 길이 0.5~30초(기본 2.5초), Ken Burns(줌인·줌아웃·좌→우 패닝), 바로 컷 / 0.4초 디졸브 |
| 자막 | 컷별 여러 줄, 상·중·하 안전 위치, 32~120px, 스타일 4종(외곽선·검은 박스·노랑 강조·핑크) |
| 훅 타이틀 | 영상 상단 고정 배너, 문구·배경색·글자색 |
| BGM | MP3·M4A·WAV 업로드, 볼륨 조절, Web Audio로 캔버스 스트림과 믹싱 |
| 저장 | canvas.captureStream(30) + MediaRecorder, 진행률 % 표시, MP4 우선 · 미지원 시 WebM + 안내 |

## 구조

- `index.html` — 편집기 화면
- `style.css` — 다크 테마 UI (모바일/PC 반응형)
- `app.js` — 렌더러·타임라인·오디오 믹싱·녹화 (의존성 없음)

## 실행 방법

별도 빌드 없이 `index.html`을 열면 됩니다. 파일을 `file://`로 열어도 대부분 동작하지만,
브라우저에 따라 로컬 파일 업로드가 제한될 수 있으니 아래처럼 간이 서버로 여는 것을 권장합니다.

```bash
python3 -m http.server 8080
# http://localhost:8080
```

## 저장 형식

- **자동 · MP4 우선**(기본): 브라우저가 MP4 녹화를 지원하면 `.mp4`, 아니면 `.webm`으로 저장합니다.
- **WebM**: 언제나 `.webm`으로 저장합니다. 유튜브 업로드에 최적입니다.

> 브라우저(특히 Chrome)가 MP4 컨테이너에 넣는 오디오는 **Opus**입니다. 아이폰 사진 앱·인스타 릴스에서는 이 오디오를 읽지 못할 수 있어, 오디오가 중요한 영상은 WebM으로 저장해 유튜브에 올리거나 편집 앱에서 MP4로 한 번 내보내는 편이 안전합니다. (영상 코덱은 MP4 = H.264, WebM = VP9)

## 참고

- MP4 녹화는 Chrome 126+ / Safari에서 지원됩니다.
- 저장은 영상 길이만큼 실시간으로 진행되므로, 녹화 중에는 탭을 유지해 주세요.
- 세로 1080×1920 고정 출력이며, 원본 비율이 다르면 잘라서 채웁니다(cover).
